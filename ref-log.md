# Reflection Document

## What did you learn from implementing a multi-agent workflow?
Implementing the multi-agent workflow helped me understand the difference between implementing simple LLM calls with basic system prompts and designing specialized agents with different roles. Splitting the app into a Planner and a Reviewer forced me to think about separation of tasks. The Planner focuses on expanding a vague prompt into a coherent day-by-day itinerary, and the Reviewer is responsible for feasibility, fact-checking, and corrections. The division made the overall system more robust and easier to reason about because each agent has a more predictable behavior and structured response. This is also closer to how humans work where each person is responsible for a specific part of a task instead of doing all the work.

# Challenges faced and how you addressed them.
The biggest challenge was prompt design: I had to be very explicit about what the Planner should do and what the Reviewer should do. If I was too vague, the agent would not understand their roles, and the Reviewer would sometimes re-plan everything from scratch instead of making revisions. I addressed this by tightening the instructions, emphasizing workflows, and specifying the exact structure and sections to follow.

# Any creative ideas, variations, or design choices (e.g., persona roles, prompt design).
I chose the structures of the output based on how I would like to see the response if I were the user. As a frequent traveler, I prefer to have a more detailed itinerary so I can choose what activities to do and in what order and at what time. A vague and general overview is not a helpful itinerary. Therefore, I dictated the output structure to be very detailed about each time period in a day and included some examples in the prompt to help the agents better understand the structure. Also, I decided to highlight pacing in the prompt. Based on my experience with AI generating itinerary, it is usually too optimistic about the travel time and the amount of time spent at each activity. As a result, too many activities are squeezed into a day, and sometimes it is unrealistic to finish them. I addressed this by explicitly asking the AI to consider breaks, wandering, and spontaneous activities to make the itinerary realistic.
